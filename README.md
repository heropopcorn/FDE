# 智能审批演示

本地网页演示，覆盖以下能力：

1. 管理员创建账号和审批流程，所有人可以发起、按节点审批。
2. 每个人可以针对某个流程配置自己的自动审批规则。单据到达该节点时，调用 OpenRouter 免费模型判断是否直接通过。
3. 在「审批助手」中对话发起申请、补齐字段、核对草稿后提交，查询自己的申请和待办。会话、草稿和记录保存在本地数据库，刷新后可继续。
4. 管理员在「审批控制」中选择自动处理、仅提供建议或暂停自动审批，配置数值条件，查看操作记录和异常恢复任务。单据详情可展开历史判断依据。

## 启动

使用 Node.js 24 LTS（需要内置 SQLite 和测试模块解析钩子）。数据保存在本机，当前未对接 OA、统一登录或消息平台。

```bash
cd approval-demo
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。

密钥放在 `approval-demo/.env.local` 的 `OPENROUTER_API_KEY`，不要提交到仓库。数据库文件是 `approval-demo/data/app.db`。向量由本机的 `bge-large-zh-v1.5` 生成，维度 1024，写入 Redis。第一次运行会把模型下载到 `.cache/transformers`。

```bash
docker compose up -d
```

## 对话办理示例

打开 `/assistant`，输入「我想请两天事假」，再补充「明天开始，事由：回家办理证件」。核对草稿卡片中的日期、天数和原因后点击「确认并提交」。

- 修改：`天数改为3`；取消：`取消草稿`。修改后必须重新确认，重复确认同一草稿只创建一张单据。
- 查询：`我的申请`、`我的请假到哪了`、`我的待办`、`查看 #1`；多项结果支持 `下一页`。查询结果来自本地记录，按当前登录账号检查权限。
- 通过与驳回仍由当前审批人在单据详情中操作，对话中的文字不会直接执行审批决定。
- 常见流程、日期和字段可在未配置模型时办理。更灵活的表述使用现有 OpenRouter；失败时保留草稿，可按字段名称补充或使用表单。

## 审批控制与恢复

管理员进入 `/admin/controls`。建议模式只记录 AI 建议，暂停模式停止新的自动判断和自动执行，人工审批继续可用；切换不会撤销已经执行的结果。模式切换后，需重新判断的历史单据可使用详情页中的重新判断入口。

数值规则需根据实际业务制度配置，默认不假设审批额度。命中规则、所需制度检索失败或规则在判断期间变化时转人工。模型请求会过滤常见敏感字段并遮盖手机号、证件号、邮箱等内容；这属于基础过滤，不能代替完整的数据分类与脱敏制度。

判断依据保存个人规则版本、引用制度片段和版本、结果及是否自动执行。重试保留历史快照。操作日志、判断快照和制度版本由数据库触发器限制更新和删除，供本地追溯使用。

单据处理使用本地 SQLite 持久队列和带续期的单据锁。应用启动时及每 10 秒恢复一次中断任务，失败退避重试，连续 5 次失败后可在审批控制页面重新排队。人工待办或模型失败转人工属于正常业务状态，不在后台无限重复调用模型。部署需保持一个常驻 Node.js 服务及持久数据库文件；当前不支持跨机器共享数据库或无服务器多实例。

可选环境变量：

| 变量 | 用途 |
| --- | --- |
| `OPENROUTER_CHAT_MODEL` | 对话字段提取优先模型，其次读取 `OPENROUTER_MODEL`，默认 `poolside/laguna-s-2.1:free` |
| `ASSISTANT_MODEL_ENABLED=0` | 关闭对话中的模型提取，保留本地常见语句和字段办理 |
| `DATA_DIR` | 项目下独立数据文件夹名称，默认 `data` |
| `SKIP_KB_INDEX=1` | 跳过启动时的知识索引，供隔离测试使用 |
| `APPROVAL_WORKER_DISABLED=1` | 关闭后台恢复定时任务，供测试使用 |

对话字段提取关闭额外推理并要求 JSON 输出，优先选择低延迟服务节点。优先模型限流或不可用时，由 OpenRouter 尝试 `dots-studio/dots-3-note-preview:free`，整个请求保留 60 秒超时上限。服务端日志记录模型名称、耗时和错误类别，不记录用户输入、模型原文或密钥。

## 验证

```bash
npm test
npm run lint
npm run build
```

自动测试使用独立临时数据库和模拟模型响应，覆盖草稿确认、权限、重复提交、模式切换、数值规则、依据版本、并发审批及任务恢复。测试通过不代表真实业务审批准确率已经验证。
